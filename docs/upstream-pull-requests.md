## Additional review findings

The review also found retained subscription patches that refer to instances already removed from the current tree. Converting those patches previously panicked while holding the tree mutex. The fork rejects stale replay with a WebSocket restart close and asks the client to reconnect for a fresh tree. Sourcemaps conservatively rebuild when a historical ID can no longer be inspected. These are fork fixes, not claims that an upstream proposal already solved the problem.

## Validation boundaries

Server tests cover deterministic behavior and Windows filesystem churn. Linux and macOS watcher behavior still needs their respective CI runners. Plugin unit tests require Roblox Studio; static formatting or a successful plugin build does not establish live Studio behavior. Upload endpoint changes, automatic place opening, multiple paths, custom names, child patterns and the third-party headless API remain deferred as recorded above.
