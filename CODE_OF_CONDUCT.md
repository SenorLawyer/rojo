# Community conduct

Contributions and bug reports are welcome regardless of experience. Critique the change and explain how to reproduce the problem. Do not harass contributors, disclose personal information, or post credentials or private project files.

These expectations apply to this fork's issues, pull requests and reviews. Use GitHub's report menu on abusive comments. The maintainer may hide comments, lock a discussion or block repeated abuse. Security reports have a [private channel](.github/SECURITY.md).
